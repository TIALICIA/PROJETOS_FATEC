## 📌 Sobre o projeto

O **App Restaurante** é um projeto desenvolvido utilizando Flutter, com o objetivo de explorar o desenvolvimento de aplicações mobile e a construção de interfaces voltadas ao contexto de restaurantes.

A proposta é aplicar conceitos de programação para dispositivos móveis, organização de componentes, navegação e desenvolvimento de interfaces utilizando tecnologias multiplataforma.

## 🚀 Tecnologias utilizadas

| Tecnologia | Aplicação |
|---|---|
| Flutter | Framework para desenvolvimento mobile |
| Dart | Linguagem de programação |
| Material Design | Componentes e interface visual |

## ⚙️ Como executar o projeto

### Pré-requisitos

- Flutter SDK instalado.
- Dart SDK.
- Android Studio ou Visual Studio Code.
- Emulador Android ou dispositivo físico.

### Instalação

1. Clone o repositório:

```bash
git clone https://github.com/TIALICIA/PROJETOS_FATEC.git
```

2. Acesse a pasta do projeto:

```bash
cd PROJETOS_FATEC/4_SEMESTRE/Prog_para_dispositivos_moveis/app_restaurante
```

3. Instale as dependências:

```bash
flutter pub get
```

4. Execute a aplicação:

```bash
flutter run
```
